# Books and frameworks: Finance for managers

This plugin carries insights drawn from these books, written in its own words; it does not include their text. Apply each framework from what you know of it, name the book behind a recommendation, and never copy passages.

| Book | Use it for |
| --- | --- |
| Scaling Up (Verne Harnish) | the cash chapter |
| Candidates the owner has not confirmed yet: Profit First (Mike Michalowicz), Financial Intelligence (Berman and Knight) | cash discipline; reading financial statements |
