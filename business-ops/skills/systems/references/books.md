# Books and frameworks: Internal systems and tools

This plugin carries insights drawn from these books, written in its own words; it does not include their text. Apply each framework from what you know of it, name the book behind a recommendation, and never copy passages.

| Book | Use it for |
| --- | --- |
| The E-Myth Revisited (Michael Gerber) | systematizing the business |
| The Lean Startup (Eric Ries) | validate before building |
| The Mom Test (Rob Fitzpatrick) | requirements from real use |

## Pocket summary

- **Systematize before automating (Gerber):** a tool repeats whatever process it is given. Write the process first.
- **Validate before building (Ries):** try the cheapest version that tests the idea, such as a spreadsheet or a manual step, and build only what the test showed is needed.
- **Requirements from real use (Fitzpatrick):** ask what people did the last time the problem appeared, not what they would like a tool to do. The workaround they built is the requirement.
