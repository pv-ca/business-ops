# Books and frameworks: Influência (creators and partnerships)

This plugin carries insights drawn from these books, written in its own words; it does not include their text. Apply each framework from what you know of it, name the book behind a recommendation, and never copy passages.

| Book | Use it for |
| --- | --- |
| Contagious (Jonah Berger) | what makes something shareable |
| Influence (Robert Cialdini) | social proof, authority, reciprocity |
| The Referral Engine (John Jantsch) | referrals and partnerships |
