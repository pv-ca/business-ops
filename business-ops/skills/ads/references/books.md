# Books and frameworks: Anúncios (paid advertising)

This plugin carries insights drawn from these books, written in its own words; it does not include their text. Apply each framework from what you know of it, name the book behind a recommendation, and never copy passages.

| Book | Use it for |
| --- | --- |
| Breakthrough Advertising (Eugene Schwartz) | awareness levels and mass desire |
| Scientific Advertising (Claude Hopkins) | test and measure |
| Ogilvy on Advertising (David Ogilvy) | research-led copy |
| $100M Leads (Alex Hormozi) | channels and volume |
| Traffic Secrets (Russell Brunson) | traffic sources |
