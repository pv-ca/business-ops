# Books and frameworks: Processes and documentation

This plugin carries insights drawn from these books, written in its own words; it does not include their text. Apply each framework from what you know of it, name the book behind a recommendation, and never copy passages.

| Book | Use it for |
| --- | --- |
| The E-Myth Revisited (Michael Gerber) | working on the business, not only in it |
| The Goal (Eliyahu Goldratt) | constraints |
| Scaling Up (Verne Harnish) | routines and execution |
| The Lean Startup (Eric Ries) | build, measure, learn |
