# Books and frameworks: Pesquisa de mercado (market and customer research)

This plugin carries insights drawn from these books, written in its own words; it does not include their text. Apply each framework from what you know of it, name the book behind a recommendation, and never copy passages.

The working method file is `customer-research-playbook.md` in this folder.

| Book | Use it for |
| --- | --- |
| Deploy Empathy (Michele Hansen) | neutral interviewing, scripts, recruitment; the principal source of the playbook |
| The Mom Test (Rob Fitzpatrick) | asking without bias; past behaviour over opinions |
| Competing Against Luck (Clayton Christensen) | jobs to be done |
| Demand-Side Sales 101 (Bob Moesta) | switching interviews and forces of progress |
| Obviously Awesome (April Dunford) | alternatives and unique value |
| Blue Ocean Strategy (Kim and Mauborgne) | uncontested market space |
